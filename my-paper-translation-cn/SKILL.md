# 论文中文翻译

将用户提供的论文 PDF 翻译成可独立阅读的中文 Markdown，默认自动完成全部批次。用户指定翻译范围、批次数量或暂停时，以用户要求为准。

## 文件与原文准备

- 最终译文默认保存到工作目录的 `translation/<论文文件名去扩展名>.md`；用户指定路径时优先使用指定路径。
- 所有中间文件保存到工作目录的 `tmp_gpt/translation/<论文标识>/`；论文标识须区分同名的不同 PDF。
- 优先读取 PDF 文字层；扫描版或异常页面使用可用的 OCR 或页面查看能力。
- 以 PDF 实际页序计页，另记印刷页码；结合页面核对双栏、跨页段落和浮动图表的阅读顺序。
- 翻译前识别正文结构及排除范围，按 [进度文件与工具协议](references/state-protocol.md) 建立可回查的原文索引和批次计划。

## 翻译范围与忠实性

- 翻译标题、摘要和正文，包括结论、正文脚注、图注、表题与表注；保留章节编号、标题层级、段落顺序及论述关系。
- 不删减或压缩，不添加原文没有的解释，长表概括除外。使用流畅的学术中文，术语全文一致；首次出现时可保留必要的英文或缩写。
- 排除参考文献、附录及明确标记的补充材料，包括其中的公式和代码；按章节归属判断，不按页面位置截断正文。
- 正文公式与原文一致，保留符号、上下标、结构、编号及引用，使用 `$...$` 或 `$$...$$` 输出 LaTeX。
- 正文代码原样保留，相关自然语言说明翻译成中文。
- 原文无法读取或辨认时，记录位置、说明限制并核对 PDF；仍无法解决则标记待核对，不猜测补全。

## 图片与表格

- 不插入图片。保留图号及引用，翻译图注与说明，放在接近原文的逻辑位置。默认不逐项转录图内坐标轴和图例文字，用户另有要求时遵从。
- 保留表号，翻译表题和必要表注。正常表格使用 Markdown 表格，复杂表头可采用其他忠实表达关系的 Markdown 排列；保留数值、单位、比较标记及注释关联。
- 表体超过 300 个非空白字符时，改为明确标记的“表格内容概括”。按原表单元格内容计数，含文字、数字和符号，不计表题与表注。概括保留比较对象、指标、主要结果及关键条件，不增加推论。

## 自动分批

1. 将最大层级的正文结构视为“章”，摘要作为独立单元；排除内容不进入批次。
2. 每批起止 PDF 页的包含区间不超过六页，可因结构边界不足六页。
3. 在限额内优先包含至少一个完整章，并尽量纳入更多完整章；超长章在小节或段落处分批，续译批次可不含完整章。
4. 单个原文单元超过六页时，先在句子、表格行组或公式组等可核对边界拆分；仍不可拆分则记录原因、实际页数及例外，禁止静默超限。
5. 可跨批阅读上下文，但只输出本批范围，避免跨页内容重复或遗漏。
6. 中断或暂停时保存进度；恢复时按进度协议核对原文和索引，继续未完成部分。

## 执行模式

- 用户未明确要求子代理时，由当前模型按分批计划顺序翻译、核对并保存。
- 用户明确要求子代理时，读取并遵循 [并行交互协议](references/parallel-translation.md)。
- 不具备代理能力时说明限制，不声称已并行执行；用户要求必须由代理翻译时保存准备结果并报告阻碍，不自行替代；否则按可用方式推进。
- 两种模式均遵循进度协议管理提交、验收和合并；工具验证结构和文件一致性，不替代原文核对。

## 核对与交付

默认审校；仅用户明确关闭时按进度协议设置 `--review off`。关闭后跳过本文件及引用协议中的逐批、全文内容审校和术语使用复审，仍保留结构校验、子代理术语表维护及新术语裁决、未决问题记录。

启用审校时，每批对照原文核对完整性、准确性、公式、图表及引用、段落边界和术语。

按进度协议合并已验收批次，最终译文不含工作记录。完成前按索引确认应翻译单元恰好覆盖一次、排除单元未混入；启用审校时另核对实际内容、跨批衔接及术语一致性。

交付时链接译文，说明完成范围、是否审校及未决问题；存在未解决内容时不得宣称全文已完整完成。
